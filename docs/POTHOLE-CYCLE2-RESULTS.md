# 포트홀 개선 실험과 최종 평가

VAL652장을 동일한 실제 앱 ONNX Runtime CPU1.31.1 경로로 평가한 뒤 Nano V8의 640 입력을 최종 연구 후보로 고정했다. 입력960·1280은 동일 가중치로 시험했으며 추가 학습이나 confidence 변경은 없었다. 두 옵션 모두 수치 변환 검사를 통과했지만 검증 AP50이 낮아 선택하지 않았다. 더 큰 Small 모델도 기존 도메인 VAL 하락 제한을 넘겨 제외했다.

| 평가 집합 | 기준 V6 AP50 | 선택 V8 AP50 |
|---|---:|---:|
| 기존 RDD VAL402 | 65.68% | 64.34% |
| MWPD VAL250 | 59.15% | 62.24% |
| 동일 가중 VAL 평균 | 62.41% | 63.29% |
| 새 미국 TEST100 | 45.49% | 42.25% |
| 과거 회귀 TEST145 | 60.03% | 63.40% |

**새 미국 평가에서 AP50 목표80%를 충족하지 못했다.** 회귀 점수는 개선됐지만 새 평가의 점수는 기준보다 낮다. 이 결과를 보고 후보나 임계값을 바꾸지 않았으며 두 cohort를 각각 한 번만 평가했다. 운영 승인이나 현장 정확도 향상으로 표시하지 않는다.

미국100장은 사전에 고정한 한 국가의 양성50장과 게시자 no-D40 음성50장이다. 기존145장은 MWPD 양성97장과 RDD no-D40 음성48장으로 이미 평가했던 회귀 자료다. 물리적인 도로·주행 세션 독립성과 완전한 음성 라벨을 보장하지 않는다. 실물 ZED 2i·깊이·현장 성능은 이번 점수에 포함하지 않았다.

Small 재실행은 동일 초기화·학습 규칙으로20epoch, 실제 optimizer5,112회 갱신 후 사전 중단 규칙에 따라 끝났다. 마지막 VAL은 기존54.77%·MWPD71.33%였고, 기존 도메인 하락 제한3%p를 충족하지 못했다. 진단 체크포인트는 로컬에 보존했으며 배포용 ONNX는 내보내지 않았다. 앞선 공유 GPU 자원 한도 중단 기록도 보존했다.
