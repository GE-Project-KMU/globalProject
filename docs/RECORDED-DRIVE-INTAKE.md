# ZED 2i 녹화 주행 자료 인계

원본은 프로젝트의 `data/incoming/drive/` 등 Git 제외 경로에 둔다. 현재 자료는 다른 보유자로부터 전달받기 전 상태이며 실제 주행 영상·GNSS를 실행하거나 정확도/FPS를 측정하지 않았다.

## 전달받을 파일과 정보

- MP4로 변환하지 않은 `.svo2` 또는 `.svo` 원본. 분할 녹화라면 모든 조각과 순서.
- 녹화 도구와 ZED SDK 버전, ZED 2i 카메라 일련번호, 해상도·FPS·압축 방식, 실제 촬영 시작 시각과 시간대.
- 가능하면 해당 카메라의 `SNxxxxxxx.conf`와 차량 장착 높이·각도·ROI 보정 기록. 일반 카메라 보정과 차량 장착 보정은 서로 다르다.
- 별도로 기록한 GNSS/NMEA 또는 SVO2에 직접 저장한 외부 GNSS 데이터. 수신기 종류·로그 시각 기준·동기화 방식도 필요하다. 카메라 녹화만으로 GPS가 자동 제공된다고 가정하지 않는다.
- 수집 목적·촬영 권한·고지·보관 기한. 전달 또는 파일 복사 시각을 촬영 시각으로 삼거나 기존 원본 기한을 연장하지 않는다.

ZED SDK4.1부터 SVO2가 기본이며, 기존 SVO도 재생 대상이다. SVO/SVO2에는 스테레오 영상과 시각·센서 메타데이터가 들어 있고, depth 등 SDK 처리 결과는 재생 시 계산한다. SDK 버전과 보정 설정도 재현 기록에 포함해야 한다. 근거는 [공식 녹화 문서](https://docs.stereolabs.com/docs/development/zed-sdk/modules/camera/recording), [SVO2 기본 형식 안내](https://support.stereolabs.com/articles/2249319099-what-is-the-file-size-for-videos-recorded-by-the-zed-cameras), [오프라인 보정 파일 설정](https://docs.stereolabs.com/docs/development/zed-sdk/offline-deployment)이다.

## 수령 후 검증 순서

1. 원본 경로·바이트 해시·파일 크기·촬영 시각·원래 만료일을 로컬 인계 기록에 고정한다. 영상·GNSS·개별 프레임·위치·카메라 식별자는 Git에 올리지 않는다.
2. 처음1~2분으로 파일 손상, 좌우 영상, 실제 해상도/FPS, 프레임 시각 단조성·공백, 보정 일치 여부를 확인한다.
3. MP4는 좌우 side-by-side 여부를 명시하고 기존 영상 어댑터로 검증한다. 단안 MP4를 스테레오로 분할하거나 그 자료로 depth 정확도를 주장하지 않는다.
4. SVO/SVO2는 해당 파일과 SDK 버전을 확인한 뒤 녹화 파일 입력 어댑터를 연결한다. 현재 `agent.equipment.ZedSDK`는 선택적 **실시간 카메라** 어댑터이며 녹화 파일 입력 연결과 실제 SDK 검증은 아직 남아 있다. SDK가 없으면 전역 설치를 자동 실행하지 않는다. 프로젝트 내 설정 경로와 로그 경로를 지정하고, 보정 경로의 끝 구분자까지 확인해야 한다([공식 수정 이력](https://docs.stereolabs.com/docs/development/zed-sdk/release-notes/5-x/5-5)).
5. 촬영 당시 시간·GNSS를 정렬한다. GNSS나 시각 근거가 없으면 위치·물리 거리 관련 값은 null/판정 불가로 두며 현재 시각이나 예제 좌표를 입력하지 않는다.
6. 고정 모델로 탐지→추적→검수 대기→사용자 검수→전송→관측 상세까지 확인한다. 원본을 서버에 그대로 공개 업로드하거나 사람이 검수했다고 자동 표시하지 않는다.
7. 충분한 길이가 있으면60분 재생의 처리량·지연·자원·메모리 증가·오류·재시도를 측정한다. 빠른 파일 재생, 실시간 제한 재생, 실제 차량 수집 성능은 각각 다른 지표로 기록한다.

영상만 있고 포트홀·도막·개인정보 정답이 없으면 동작과 처리량 검증은 가능하지만 AP/IoU/Recall을 계산할 수 없다. 정확도 평가용 구간은 먼저 동결·라벨링하고 학습에서 제외한다. 사용자 영상은 전달만으로 자동 학습에 편입하지 않는다. 새 주행의 진동·장착 안전·2개 차종 현장 시험 및5명 담당자 사용성 시험은 녹화 재생으로 대체하지 않는다.
