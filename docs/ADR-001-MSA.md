# ADR-001: 서비스 경계와 개발 체크포인트

날짜: 2026-11-03

사용자가 구현 단계에서 이식성 및 MSA 구성을 지정했으므로, 기존 SDD의 단일 서버 참조 구성을 다음 서비스 경계로 변경한다. Notion에서 가져온 문서는 요구사항 기준 스냅샷이며 실제 구현 완료 증거가 아니다.

| 서비스 | 로컬 포트 | 소유 데이터 |
|---|---:|---|
| identity | 8101 | 기관·사용자·세션·기기 자격증명 |
| media | 8102 | 공유 승인·비식별 이미지·파일 삭제 |
| inspection | 8103 | 주행·관측·점검 건·검토·중복 연결 |
| analysis | 8104 | 설치 보정·모델 manifest·분석 작업 |
| reporting | 8105 | 출력 작업·보고서 스냅샷·삭제 요청 조정 |
| gateway | 8000 | 외부 라우팅·인증 문맥 전달, 도메인 DB 없음 |

도메인 간 통신은 내부 HTTP로 수행한다. 서비스별 DB를 소유하며 다른 서비스 테이블을 조회하거나 외래키를 걸지 않는다. 공통 라이브러리는 저장 기술·서명·오류 응답 등 기술 코드만 공유한다.

초기 저장 방식은 기관·종류별 JSON 집합체와 version을 사용하는 서비스별 저장소다. SQLite 로컬 개발과 PostgreSQL JSONB 참조 배포를 지원한다. SDD의 정규 관계 테이블/공간 인덱스는 별도 마이그레이션·운영 규모 검증이 필요한 설계이며 현재 구현됐다고 주장하지 않는다.

외부 토큰은 identity에서 확인하고 Gateway가 대상 서비스용 짧은 수명의 내부 인증 문맥을 만든다. 개발용 내부 비밀값은 프로젝트 `.env`로 주입한다. 인터넷 운영 시 네트워크 격리·서비스별 자격증명·키 교체·TLS 구성을 별도 검증한다.

원본 영상은 로컬 agent에 머문다. 대상 도메인 학습 가중치가 없으면 추론을 차단하고 `model_not_ready`를 반환한다. 일반 객체 모델 결과를 포트홀 성능으로 표시하지 않는다.

Git은 `main` 기준, 개발은 `feat/msa-mvp`에서 진행한다. API·컴포넌트별 커밋을 유지하고 검증 결과와 미검증 범위를 기록한다. 첫 체크포인트에는 아직 미완성 서비스와 미실행 통합 테스트가 포함되며 배포 완료 상태가 아니다.
