# 포트홀 v6 기존 검증 자료의 오류 원인 집계

기존 RDD2020 VAL 402장과 MWPD VAL 250장만 v6의 실제 ONNX·애플리케이션 CPU 경로로 추론했다. **TEST 사진·예측은 사용하지 않았으며, 새 미국 100장도 사용하지 않았다.** 가중치·운영 임계값은 바꾸지 않았다. 현재 운영 confidence 0.1, IoU 0.5 일대일 매칭 기준의 결과다.

| 기존 VAL | GT 객체 | TP | FN | FP | Recall | Precision |
|---|---:|---:|---:|---:|---:|---:|
| RDD2020, 402장 | 330 | 231 | 99 | 183 | 70.0% | 55.8% |
| MWPD, 250장 | 539 | 379 | 160 | 468 | 70.3% | 44.7% |

아래 크기는 실제 거리나 물체 길이가 아니라 **640 입력의 종횡비 유지 축소율을 곱한 GT 박스 면적의 제곱근**이다.

| 크기 구간(px) | RDD GT / FN / Recall | MWPD GT / FN / Recall |
|---|---|---|
| 16 미만 | 4 / 2 / 50.0% | 0 / 0 / 해당 없음 |
| 16 이상 32 미만 | 75 / 27 / 64.0% | 10 / 5 / 50.0% |
| 32 이상 64 미만 | 176 / 46 / 73.9% | 113 / 46 / 59.3% |
| 64 이상 | 75 / 24 / 68.0% | 416 / 109 / 73.8% |

전체 FN 259개 중 32px 미만은 34개(13.1%)이고, 32px 이상은 225개(86.9%)다. 작은 객체의 누락은 존재하지만, 그것만으로 전체 오류를 설명할 수 없다. 특히 MWPD의 큰 박스에서도 FN 109개가 남는다. 해상도 확대가 중간 크기·박스 위치 정확도에 도움을 주는지는 다음 후보의 VAL로 확인할 수 있지만, 현재 집계만으로 개선을 보장하지 않는다.

같은 추론 결과의 confidence 0.01 보조 집계에서는 Recall이 RDD 82.1%, MWPD 82.4%로 올라가지만 FP는 각각 644개·2,577개, Precision은 29.6%·14.7%다. 이 보조 집계는 원인을 살피기 위한 것으로 임계값을 변경하거나 재선택한 결과가 아니다. 임계값을 낮추는 것만으로 목표 Recall을 충족한다는 근거도 없다.

추가 사진 읽기나 모델 실행 없이 기존 VAL 예측 메타데이터의 오류도 분해했다. FN 중 어떤 운영 예측과도 IoU 0.1에 미치지 못한 객체는 RDD 61개·MWPD 78개이고, IoU 0.1 이상 0.5 미만의 겹침이 있는 객체는 각각 38개·82개다. 후자는 위치 추정이나 라벨 차이 가능성을 보여 주지만 사람의 확인 전에는 원인을 확정할 수 없다. MWPD FP 468개 중 217개는 GT와 그 정도로 겹치며 236개는 IoU 0.1 미만, 15개는 중복 검출 등 일대일 매칭 충돌 가능성이 있다. RDD의 GT 없는 사진 201장에서는 FP 35개가 발생했다. 따라서 위치 추정·도메인 및 배경 혼동·confidence 문제를 함께 검토할 근거가 된다.

CPUExecutionProvider만 사용했고 ORT 2스레드·스피닝 끔·OpenCV 1스레드로 실행했다. 단일 모델 추론 지연 중앙값은 27.4ms, p95는 36.9ms였다. 사진 디코딩·전체 파이프라인을 제외하고 다른 GPU 학습과 CPU를 공유한 호스트에서 측정한 값이므로 카메라 처리 FPS나 다른 장비 성능으로 환산하지 않는다.

이는 이미 사용 중인 검증 자료의 다음 연구 설계를 위한 진단이며 독립 성능 평가나 운영 승인 결과가 아니다. 출판자 라벨에 의존하므로 미주석 결함·라벨 차이 가능성도 남는다. 공개 JSON은 집계와 전체 증거 파일의 해시만 포함하고, 개별 GT·예측·이미지 식별자·좌표는 공개하지 않았다. 개별 파생 메타데이터는 원자료의 최소 보관 기한인 **2026-11-10 17:14:46.862846 UTC**를 상속한다.
