# 포트홀 TRAIN 난이도 가중치 준비 결과

기존 포트홀 v6의 실제 ONNX를 CPU로 실행해 **원 TRAIN 7,540장**의 샘플별 난이도 가중치를 만들었다. 사전 동결한 소스와 규칙을 그대로 사용했으며 VAL·TEST·새 미국 100장·사용자 주행 영상은 추론이나 가중치 계산에 사용하지 않았다. 모델·가중치·confidence 0.1·기존 NMS도 유지했다.

|---|---:|---:|---:|---:|---:|---:|

GT와 예측을 confidence 내림차순·IoU 0.5 일대일로 매칭했다. 양성 사진은 `1 + 2 × min(1, (FN + FP) / (GT + 3))`, 음성 사진은 `1 + 2 × min(1, FP / 3)`으로 계산한다. 모든 값은 유한한 1~3 범위다. 출처별 25%·25%·50% 할당량은 학습기가 별도로 보장해야 하며, 이 도구는 출처 사이의 비율을 정규화하거나 변경하지 않는다.

개별 결과는 비공개 `training-weights.json`의 `samples` 배열로 제공한다. 각 항목은 `sample_id`, `sha256`, `stratum`, `weight`, `gt_count`, `tp`, `fp`, `fn`을 가진다. 헤더에는 사전 계획·출처 release·정확한 TRAIN 멤버십·모델 manifest·ONNX의 해시와 원래 만료 시각을 기록했다. 학습기는 완료 receipt, 파일 해시, 7,540개 멤버십, 클래스별 출처 수, 1~3 범위 및 만료 시각을 확인한 뒤 사용해야 한다. 개별 예측 좌표는 별도 비공개 파일에 보관한다.

완료 후 원본 TRAIN 메타데이터와 저장된 예측만으로 별도 `agent.evaluate.detection_metrics` 경로를 사용해 7,540건의 TP·FP·FN을 다시 계산했다. 모든 값과 공식의 결과가 일치했고, 고유 샘플 수·이미지 해시 연결·출처 묶음·TRAIN 멤버십도 일치했다. 이 재검사는 추가 사진 읽기나 모델 실행 없이 수행했다. 공개 [집계](POTHOLE-TRAIN-HARDNESS-V8-RESULTS.json)와 [검수 결과](POTHOLE-TRAIN-HARDNESS-V8-QA.json)에는 단위별 수와 전체 증거 파일의 해시만 담고 개별 이미지 식별자·좌표·사진은 포함하지 않았다.

실제 실행은 CPUExecutionProvider·ORT 2스레드·스피닝 끔·OpenCV 1스레드이며 GPU 사용은 없었다. 단일 추론 지연의 중앙값은 31.4ms, p95는 41.1ms다. 다른 학습과 CPU를 공유한 호스트에서 측정했고 디코딩·전체 파이프라인을 제외했으므로 처리 FPS 목표 검증에 사용하지 않는다.

이 집계는 기존 학습 자료의 샘플링 준비 결과다. 정확도 개선 여부는 이후 사전 고정한 검증 절차로 확인해야 한다. FP·FN은 출판자 라벨에 상대적인 값이며 사람의 개인정보 검수나 운영 승인을 뜻하지 않는다. 개별 가중치와 예측 메타데이터의 기한은 원자료의 최소 기한인 **2026-11-10 17:14:46.862846 UTC**를 상속한다. 원자료 삭제·사진 복사·기한 연장·기존 보관 목록 수정은 없었다.
