# RDD2022 신규 외부 평가 자료 수집 결과

공식 서버의 전송 오류로 수집이 중단되어, 목표한 **200장 평가 집합은 동결하지 못했다. 새 자료에 대한 모델 추론·학습·임계값 선택은 모두 0회**이다. 현재 학습은 기존 TRAIN/VAL로 진행하며, 이미 평가한 기존 TEST는 회귀 검증으로만 취급한다. 이번 부분 수집을 새 외부 성능 검증 완료로 해석하면 안 된다.

[저자 배포 안내](https://github.com/sekilab/RoadDamageDetector), [공식 Figshare 자료](https://figshare.com/articles/dataset/21431547/1), [공식 메타데이터 API](https://api.figshare.com/v2/articles/21431547)를 사용했다. 원본 VOC XML의 문자 그대로 `D40`인 객체만 포트홀로 읽었고, 다른 도로 손상 클래스를 포트홀로 재매핑하지 않았다. 미국 4,805개·노르웨이 8,161개 XML의 개별 ZIP CRC를 확인했다. 미국 후보 사진 240개까지의 처리 완료를 확인했으나, 두 국가의 최종 균형 표본을 모두 확정하지 못했다. `D40`이 없는 라벨은 출판자 기준 음성일 뿐 사람이 확인한 무결함 도로를 뜻하지 않는다.

전송은 공식 공개 URL의 범위 요청으로 수행했다. 직접 다운로드, 공식 API 경유, 공식 서명 URL 재사용 방식을 별도 실행·출처로 구분했으며, 마지막 방식도 정해 둔 재시도 후 실패 종료했다. 마지막 범위 캐시에는 **169개 블록, 706,426,443바이트**가 남아 있다. 정확한 HTTP 206·Content-Range와 블록 SHA 증거를 요구했고, 완전히 읽은 개별 내부 멤버에 대해서만 ZIP CRC가 확인된다. **전체 13,264,172,619바이트 파일을 내려받거나 출판자 MD5를 검증한 것은 아니다.** 캐시에는 미검토 원본 사진 바이트가 포함될 수 있으므로 공유 승인된 자료로 취급하지 않는다.

사전 선정 계획은 국가별 양성 50장·음성 50장씩 두 국가, 파일명 20개 단위 묶음별 한 장이다. 기존 6개 자료 스냅샷의 모든 분할 19,069행(서로 다른 이미지 SHA 12,705개), 정확 해시·dHash 및 좌우 반전 근접 이미지, 알려진 파일명 묶음을 제외 대상으로 고정했다. 국가·파일명 묶음은 물리적인 주행 경로나 촬영 세션의 독립성을 입증하지 않는다. 최종 집합이 없으므로 집합 내부 유사 이미지 QC 역시 수행 완료로 표시하지 않는다. 모델 결과를 보고 표본을 선택한 적은 없다.

자료 라이선스는 **[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)**이며 출처 표기는 “Arya et al., RDD2022, DOI 10.6084/m9.figshare.21431547.v1”이다. 이 라이선스는 출처 표시 등 조건에 따라 상업적 이용을 허용하지만 개인정보권이나 운영 승인을 부여하지 않는다. 기존 [RDD2020](https://data.mendeley.com/datasets/5ty2wb6gvg/1)의 CC BY-NC 3.0 자료로 학습한 모델의 상용 이용 제한을 이번 자료가 없애 주는 것도 아니다. 사용자 주행 영상은 이번 수집·학습·평가에 사용하지 않았다.

캐시와 파생 메타데이터는 새 다운로드 날짜로 기간을 늘리지 않고, 앞선 동일 RDD2022 출처의 더 빠른 기한인 **2026-11-10 17:07:24.286159 UTC**를 상속한다. 기존 보관 목록은 수정하지 않았고 원본 삭제·자동 정리 등록도 수행하지 않았다. 실행 소스·사전 선정 계획·부분 수집 증거의 해시는 함께 작성한 집계 JSON에 보존하며, 공개 보고서에는 개별 사진·이미지 식별자·개별 이미지 해시·좌표·서명 URL을 포함하지 않는다.
