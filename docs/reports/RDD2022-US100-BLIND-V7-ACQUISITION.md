# RDD2022 미국 100장 오프라인 평가 집합 확보

**미국 단일 국가의 포트홀 양성 50장·출판자 기준 음성 50장, 총 100장을 별도 평가 집합으로 동결했다.** 기존 2개국 200장 전송 실패 기록은 유지하며 이번 집합을 그 목표의 달성으로 표시하지 않는다. 추가 네트워크 요청과 모델 추론은 모두 0회이며, 이 집합은 이후에도 TRAIN·VAL·모델 및 임계값 선택에 사용하지 않는다.

앞선 전송에서 완전히 보존된 범위 캐시만 읽어, 최초 고정 seed로 선정했던 미국 후보 240장의 원본 사진과 4,805개 VOC XML을 복원했다. ZIP 내부 개별 멤버 CRC·이미지 SHA·영상 크기·시각 해시를 확인했다. 과거 모든 분할의 정확·유사 이미지와 알려진 파일명 묶음을 제외한 후 후보는 양성 90장·음성 150장이었고, 후보 안의 dHash 및 좌우 반전 근접 쌍은 0개였다.

표본 선택 전에 별도 계획과 실행 소스를 동결·커밋했다. 원래 UUID를 유지하고 클래스별 UUID 사전순 첫 50장을 선택했다. 연결된 유사 이미지의 같은 클래스 묶음에서는 최소 UUID 한 장만 유지하고, 양성·음성이 섞인 묶음은 제외한다는 규칙을 사전에 정했으며 실제 후보에는 그런 묶음이 없었다. 완성된 100장은 **이미지 SHA 100개·파일명 20개 단위 묶음 100개가 모두 고유하고, 집합 내부 근접 쌍도 0개**이다. 새 경로에 파일을 쓴 뒤 실제 파일 기반 연구용 검증기를 통과한 경우에만 release를 게시했다.

원본은 [공식 Figshare RDD2022](https://figshare.com/articles/dataset/21431547/1), [공식 메타데이터](https://api.figshare.com/v2/articles/21431547), [저자 배포 안내](https://github.com/sekilab/RoadDamageDetector)에 근거한다. `D40`만 포트홀로 해석했으며 다른 손상 클래스를 바꾸어 사용하지 않았다. `D40` 없는 사진은 출판자 기준 음성으로, 사람이 확인한 무결함 도로를 의미하지 않는다. 파일명 묶음은 대체 기준이며 물리적으로 독립된 주행 경로나 세션을 입증하지 않는다.

라이선스는 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)이며 출처는 “Arya et al., RDD2022, DOI 10.6084/m9.figshare.21431547.v1”이다. 이 자료 라이선스의 상업적 재사용 허용과 개인정보권·배포 승인은 별개다. 기존 RDD2020의 비상업 조건으로 학습된 모델의 제약을 이번 자료가 없애 주는 것도 아니다. 원본 사진과 개별 메타데이터는 로컬 연구 범위이며 사람의 개인정보 검수나 운영 승인을 표시하지 않았다.

선택된 사진 100장의 내부 CRC와 SHA를 검증했지만, 전체 13GB 배포 파일의 MD5나 국가 ZIP 전체 CRC를 검증한 것은 아니다. 보관 기한은 기존 동일 출처의 더 빠른 기한인 **2026-11-10 17:07:24.286159 UTC**를 그대로 상속한다. 원자료 삭제·기간 연장·기존 보관 목록 변경·사용자 주행 영상 사용은 없었다. 프로토콜·실행 소스·완성 release의 해시는 함께 작성한 집계 JSON에 담았으며 개별 사진·식별자·좌표·개별 이미지 해시는 공개하지 않는다.
