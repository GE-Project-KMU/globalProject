# 얼굴·번호판 검출 개선: 실제 앱 CPU 비교

선택은 봉인된 시험 점수를 열기 전에 VAL508장으로 고정했다. 선택한 후보는 두 YOLOX-Nano 전문모델이며 얼굴 global+4타일, 번호판1회 추론을 수행한다. 단일 Nano가 아니다. 두 클래스의 실제 양성 VAL 영상에서 기본 strict 수치·후처리 정합성을 모두 통과했다.

## 동일 새 시험 원본400장: 주 비교

|대상|AP50 이전→선택|재현율 이전→선택|정밀도 이전→선택|
|---|---:|---:|---:|
|얼굴|65.55% → 79.98%|71.05% → 86.49%|24.78% → 17.35%|
|번호판|95.92% → 97.94%|96.00% → 98.00%|94.12% → 92.89%|

선택 confidence는 0.01이며 시험 결과로 바꾸지 않았다. 최소 클래스 재현율95% 목표: **미달**. AP50·재현율 상승과 정밀도 저하를 함께 해석해야 한다.

고정 parity 사례는 양성 GT와 동일 클래스 예측이 존재하는 VAL 표본의 ID 사전순 첫 건이었다. 정확한 검출 여부로 표본을 골라 바꾸지 않았다. 고정 후 별도 IoU0.5 일대일 확인 결과의 GT/예측/정답 대응 수만 집계 JSON에 보관했다. 수치 정합성은 전체 검출 성능의 증거와 구분한다.

## 비용과 한계

새400장 actual app CPU predict 중앙값은 26.7ms → 350.9ms, P95는 32.2ms → 381.3ms였다. 전처리·추론·후처리를 포함하고 이미지 decode와 차량 전체 파이프라인은 제외한다. 실차 FPS 인수 결과가 아니다.

알려진 클래스만 주석된 연구 자료의 조건부 지표이며 다른 클래스 미주석을 음성으로 세지 않았다. 독립 인물·노선, 음성 주행 영상의 FPR, 완전한 개인정보 비식별화 성공을 검증하지 않았다. ZED2i 실차·기관 인수는 별도이며 자동 운영 활성화하지 않는다.
