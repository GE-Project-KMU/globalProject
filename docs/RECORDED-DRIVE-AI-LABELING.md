# 사용자 주행 영상의 AI 시각 라벨 초안

## 최신 결과: 조밀한 노면 재검토 (2026-11-08)

사용자가 영상 자체를 더 확실히 살펴보고 학습용 검수 자료를 준비하도록 요청해, 기존 80장과 별개인 `session-v2-dense`에서 다시 조사했다. 16개 영상(메시지 시각 기준 합계 약 730.21초)을 끝까지 디코딩해 14,753프레임과 원본 SHA 불변을 확인했다. 약 0.25초 간격으로 선택한 2,939개 노면 crop을 251개 접촉시트에서 AI가 모두 직접 살펴봤다. 실제 최대 선택 간격은 약 0.469초이며, 원영상 아래 40%의 노면 중심 영역을 폭 640픽셀로 축소한 조사다. 전체 14,753프레임을 원해상도로 전수 판독했다는 뜻은 아니다.

선정한 의심 지점과 혼동 사례는 원해상도 원본 및 전후 프레임 총 49장으로 다시 확인했다. 최종 21개 대표 영역 중 확인된 포트홀 양성은 0개, 맨홀·노면표시·선형 흔적 등의 음성 검수 후보는 9개, 불확실·가림 보류는 12개다. 처음 맨홀로 보였던 한 영역은 원본 연속 장면에서 노면 문자의 내부 배경으로 정정했고, 어두운 덮개 후보 한 영역은 최종 crop 재검토 후 보류로 변경했다. 포트홀 양성 미확보는 전체 영상에 포트홀이 없다는 증명이 아니다.

확실한 혼동 사례에서 잘라낸 **8개 crop**은 최종 crop까지 직접 확인하고 로컬 연구 학습용 **AI 약한 음성 후보**로 따로 준비했다. PNG와 빈 YOLO 라벨은 이 crop에만 대응한다. 불확실 crop 1개는 별도 `held` 폴더로 제외했으며, 49개 원본을 일괄 빈 라벨 음성으로 내보내지 않았다. 사람 검수 완료나 독립 평가 정답으로 취급하지 않는다. 공개 포트홀 양성과 함께 학습할 후보이며, 양성이 없는 8장만으로 포트홀 탐지기를 학습하는 세트가 아니다. 모델 학습·기본 모델 변경·정확도 개선 측정은 이번 작업에서 수행하지 않았다.

최종 로컬 산출물은 다음과 같다. 중간 `annotations-ai-reviewed*.json`, `review.html`, `result-summary.json`은 최종 판정 이전 이력이며 아래 파일이 우선한다.

- `session-v2-dense/review-final.html`: 49개 원본과 대표 영역, 판정 근거를 보는 최종 오프라인 화면.
- `session-v2-dense/annotations-ai-final.json`: 원좌표 라벨, 문맥용 프레임 구분, 같은 주행 그룹, 불확실 영역.
- `session-v2-dense/negative-crops/`: AI 음성 후보 8장, 대응 라벨, 사용 목록 및 출처·crop 변환·판정 manifest.
- `session-v2-dense/survey-index.json` 및 `reviewer-*-survey.json`: 실제 조사 범위와 후보의 원본/전후 확인 기록.
- `session-v2-dense/final-summary.json`: 최종 집계와 검증 결과.

동일 주행의 원본·인접 프레임·crop은 하나의 그룹이다. 후속 연구 학습에서 채택할 때 공개 양성 학습 자료와 섞되 자체 자료를 검증/시험에 동시에 배치하지 않는다. AI 약한 음성 후보를 채택하는 것은 사람 QC나 배포 승인, 기존 독립 평가 정답의 승격을 의미하지 않는다. 새로운 학습 효과는 기존 공개 검증 자료로 별도 확인해야 한다.

집중 테스트 107개, 실제 49장 SHA/좌표 스키마, 251개 시트의 SHA와 2,939개 타일 검토 범위 대조, 8개 최종 crop의 SHA/해상도/빈 라벨 대응을 통과했다. Chromium에서 49장과 SVG 좌표 일치, 보류 12개 필터, 빈 결과, 모바일 폭, 기한 후 이미지 차단을 확인했으며 콘솔·페이지 오류와 외부 요청은 0이었다. 최종 원본 16개 SHA도 다시 대조했다. 이러한 검사는 데이터 무결성과 UI 기능의 확인이며 AI 라벨 정답률의 측정은 아니다. [비개인 최종 집계](reports/RECORDED-DRIVE-DENSE-REVIEW-SUMMARY.json)에 기록했다.

사진·세부 좌표·원본별 식별정보는 프로젝트 폴더에만 보관하고 Git에서 제외한다. 이번 산출물에도 사용자가 허용한 2026년 11월 14일 23:59(KST) 상한을 적용하며 원본 삭제·자동 보관 연장·자동 학습 등록은 하지 않았다.

## 이전 결과: 균등한 80장 초안

사용자는 2026년11월14일23:59(KST)까지 원본 영상과 파생 프레임·라벨의 처리·보관을 새로 허용했다. 이전11월5일 검증 허가나 촬영 시각을 변경하지 않고, 별도 비공개 허가 기록과 작업 폴더를 만들었다.

16개 영상을 끝까지 다시 디코딩해14,753프레임과 원본 전후 SHA를 확인했다. 영상마다 시작·25%·50%·75%·마지막의5시점, 총80개 좌측 원본 키프레임을 추출해 AI가 직접 시각 검토했다. 기존 탐지 모델의 박스나 점수를 라벨에 복사하지 않았다. 전체14,753프레임을 시각 라벨링한 결과는 아니다.

| AI 초안 항목 | 수량 |
|---|---:|
| 검토한 대표 프레임 | 80 |
| 명확한 포트홀로 확인한 박스 | 0 |
| 노면 문자·화살표·횡단보도·선형 흔적 등의 유사 음성 영역 | 16 |
| 불확실 영역 | 8 |
| 가시 도막의 부분 폴리곤 | 98 |
| 부분 번호판 박스 | 33 |
| 초안 / 보류 프레임 | 69 / 11 |

수량은 프레임별 주석 수이며 서로 다른 실물 수가 아니다. 선정 키프레임에서 명확한 포장재 탈락 공동을 확인하지 못했다고 해서 전체 영상의 포트홀 부재를 확정하지 않는다. 검은 패치·그림자·빛 번짐은 포트홀 양성으로 억지 확정하지 않았다. 실제 마모율·깊이는 판정하지 않았다. 도막 경계는 근사 시각 폴리곤이며 완전한 픽셀 마스크나 전체 도막 주석이 아니다. 번호판 문자는 전사하지 않았고 얼굴·번호판 전체 주석이나 완전한 비식별화를 주장하지 않는다.

해질 무렵·조명 번짐·차량 및 유리 상단 가림·모션블러가 확인돼 현재 주간 대상과의 조건 차이도 기록했다. 이 자료는 검수·후속 데이터 정제의 초안이며, 사람 검수 완료나 독립 평가 정답으로 취급하지 않는다. 모든 자료를 하나의 동일 주행 그룹에 두고 프레임별 무작위 train/test 분할을 만들지 않았다. 학습 내보내기·프로젝트 탐지 모델의 추가 학습은 수행하지 않았으므로 정확도 상승 효과는 아직 측정하지 않았다.

## 로컬 결과

모든 사진·세부 라벨·원시 메시지 시각·파일별 해시는 Git에서 제외한 `data/recorded-drive-ai-labeling/` 내부에만 보관한다. 새 자료의 상한은11월14일23:59(KST)이며 원본을 수정·삭제하거나 자동 삭제를 예약하지 않았다. 요청한 AI 시각 검토를 위해 이미지를 assistant에게 제시했지만 GitHub·Notion·외부 저장소에 원본이나 라벨을 업로드하지 않았다.

- `session-v1/annotations-ai-draft.json`:80장 원좌표 초안과 사유, 미검수/보류 상태.
- `session-v1/review.html`: 원본 위 bbox·polygon을 겹쳐 보는 오프라인 검수 화면. 상태·영역 필터와 키보드 이동을 제공한다.
- `session-v1/frame-index.json`: 키프레임·원본 해시·EOF·메시지 시각 연결의 비공개 기록.
- `session-v1/review-browser-validation.json`: 실제 브라우저 시험 결과.

검수 화면은 기한 후 이미지 로드를 중단하지만 정적 파일의 복사·클라이언트 시계 변경까지 통제하는 권한 서버가 아니다. 정적 화면이 데이터를 삭제하거나 허가 기간을 연장하지 않는다.

## 재현 도구와 확인 범위

`prepare_visual_recording_review.py`는 명시적 허가·상한·원본 해시·EOF·기한을 검사하고 새 폴더에만 추출한다. `validate_visual_annotation_bundle.py`는 좌표·폴리곤·원해상도 RLE·초안 상태·같은 주행 그룹·허가 SHA·기한을 검사하며 `--verify-frame-hashes`에서 실제 PNG 해시까지 대조한다. `render_visual_annotation_review.py`는 검증된 초안으로 로컬 HTML만 생성한다. 기존 폴더·출력을 덮어쓰지 않는다.

집중 합성 검사58개를 통과했다. 실제80개 PNG의 해시와 헤더 해상도를 대조했고, Chromium에서80장 로드·SVG 원좌표 viewBox·보류11개 필터·빈 필터·모바일 레이아웃·기한 후 로드 차단을 확인했다. 콘솔/페이지 오류와 외부 네트워크 요청은0이었다. 이 검사는 라벨 형식과 화면 기능의 근거이며, AI 판단의 정답률을 측정한 것은 아니다. [비개인 집계](reports/RECORDED-DRIVE-AI-LABELING-SUMMARY.json)에 결과를 기록했다.
